# Stress Relief Game v1
一款轻量网页解压小游戏，浏览器直接运行，舒缓情绪、释放压力。

## 🎮 Play Now | 立即体验
**Online Demo 在线试玩：https://mia-mi-mi.github.io/

## 📖 About This Game | 游戏介绍
No downloads or installations required. Play instantly through the online link.
无需下载安装，点击上方链接即可直接游玩。

If you prefer local deployment: download the source code and double-click `index.html`.
如需本地运行：下载源码，双击 index.html 启动游戏。

The game language depends on your browser's language configuration. Simple operations for daily stress relief.
游戏语言由你的浏览器语言配置决定，操作简单，适合日常放松解压。

## 📥 Run Locally | 本地游玩
1. Download the latest zip package from Releases
   在 Releases 下载最新压缩包
2. Extract all files
   解压全部文件
3. Open `index.html` with a web browser
   使用浏览器打开 index.html

## 📂 Project Structure | 项目结构
- `index.html`: Main entry file 主程序入口
- `outputs`: Game resource directory 游戏资源文件夹
